**运行方法：游戏详情 → 独立运行设置 → 运行内存 → 512 KiB（旧机型），然后重新运行。** 默认 8 MiB 冒烟依然失败，原始结果保持不变；本项按已验证的明确配置结案，不能表述为默认配置已自动兼容。

## 独立设置与验证

运行内存选项覆盖全局设置、桌面游戏详情、移动设置面板、在线商店详情与播放器抽屉，通过已有 game key 保存、沿 worker profile 传递。浏览器实测 localhost:5188：全局 512 KiB 刷新保留；恢复全局 8 MiB 后，为“三国英雄传”单独选 512 KiB，启动播放器正确显示该值。

独立核验还发现播放器选择器原先读取游戏覆盖值，却总把修改写回全局。现改为存在当前游戏 key 时写入该游戏设置。实测在播放器将内存改为 256 KiB，刷新后保持 256 KiB，再恢复 512 KiB；返回首页，全局仍为 8 MiB。其他全局音量、主题等未改写保存规则。
