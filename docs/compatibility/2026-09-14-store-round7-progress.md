# 第七轮：内存包解压失败的 ABI 返回约定

## 已修复的具体错误

2442「越狱吧吊丝」原先在启动时因 `invalid deflate distance` 终止。外层 MRP 并未证明损坏：逐项用本项目解压器与 Node zlib 解压，五个压缩条目均成功且输出长度相同。实际失败的是 guest 构造的顺序 RAM MRP：总长 1286，条目 `abc` 从偏移 24 开始，压缩长 1262。这个压缩流同时被本项目和 zlib 拒绝（后者报 `invalid distance too far back`）。证据位于 `artifacts/compat-20260914/round7-probes/2442-archive.json`、`2442-read.log`、`2442-failed.gz`。

原平台 `/Users/zixing/Downloads/rxgj-main/src/mythroad/mythroad.c:1630-1655` 的 `_mr_readFile` 在调用 `mr_unzip` 前发布 gzip 尾部的输出长度；解压失败时释放缓冲区并返回 NULL。本项目 RAM 分支直接把 `MrpFormatError` 抛出，阻止 guest 自行处理失败。

本轮让 RAM 压缩条目的读取遵循该约定：发布输出长度，仅捕获格式错误并返回 NULL；其他异常继续抛出。原始包、严格解压器、内存越界检查均未修改。测试覆盖损坏 deflate、长度输出、不泄漏分配、存在性查询、失败后原始数据查询以及非法 guest 指针仍抛错。
