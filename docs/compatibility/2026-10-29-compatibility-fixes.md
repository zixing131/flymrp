## 合辑下载适配的范围

从合辑自带 `httppro.mr`、`dealdowncode.mr` 还原了 36 字节头、TLV appid 和 16 位长度命令流。客户端原本通过 `code` 命令加载服务端字节码，因此实现 `_loads`/`_loadBuf` 返回闭包，并提供使用公开文件 API 的下载处理脚本。16 KiB 数据块写入 `.part`，收到 `fileend` 后关闭、rename，原包菜单负责完成提示及启动。测试验证最终文件与输入包逐字节一致。

运行时优先使用 SD 中已有的完整同 appid 包；浏览器也可从当前商店目录获取匹配屏幕的真实包，校验长度、MD5 和 appid。EdgeOne `/blob` 路径和暂时失败后的重试均有测试。只有已知 258 下载操作获得包响应；未知操作、缺包、坏包返回失败，没有恢复原厂在线服务或伪造更新列表。

真实包验证覆盖：316015 齐天大圣孙悟空、390053 梦幻群侠传、302025 野蛮女教师、309011 冒险岛2、390041 中国象棋大师、301032 魔塔之英雄无敌。目录读取测试使用冻结商店清单和真实缓存字节，生产解析器、MD5 校验、协议处理及客体代码保持原样；另验证已安装 SD 包不依赖目录下载。场景证据位于 `legacy-functional3-401`、`legacy-functional3-991`、`legacy-functional-item-*`、`legacy-return-lifecycle`。原始 `needs-scene-review` 标签保留，人工观察作为独立字段记录。
